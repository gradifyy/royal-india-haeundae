# Royal India Haeundae concept website

A bilingual English/Korean restaurant website demo for Royal India Haeundae in Busan.

## Content updates

- Restaurant details, contact information, ratings, booking links and owner-verification notes live in `data/restaurant.ts`.
- Menu categories, dishes, translations, future prices, dietary attributes and availability live in `data/menu.ts`.
- Generated concept photography lives in `public/images/` and is clearly identified in the interface. Replace these files with approved restaurant photography while preserving the filenames, or update the image paths in the data/page files.
- Opening hours, dish-level dietary tags and the structured-data price range are intentionally withheld until the owner verifies them.

## Local development

Use the project scripts defined in `package.json`. The site is built with Vinext, TypeScript and Tailwind CSS for deployment through ChatGPT Sites.
